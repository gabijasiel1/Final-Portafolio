# Personal Portfolio Using React

This is a responsive personal portfolio website built with React and Vite. It includes a home section, about section, projects section, contact form validation, smooth scrolling, CSS animations, and local visual assets.

## Features

- Responsive single-page portfolio layout
- Home section with a background image
- About section with bio, skills, and interests
- Projects section with three project cards, images, descriptions, and links
- Contact form with name, email, and message validation
- Persistent navbar and footer
- CSS animations and smooth scrolling
- GitHub Pages deployment script

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Update the `homepage` field in `package.json` if your repository name is different, then run:

```bash
npm run deploy
```
